The **Arduino PLC IDE** — used to program Arduino industrial products such as the Portenta Machine Control and Opta with IEC 61131-3 languages — can connect its projects to Arduino Cloud. This lets PLC variables be published to the Cloud, visualized on dashboards, and shared with the rest of the platform, bridging industrial control programs with Arduino Cloud's IoT tooling.

The PLC IDE Cloud configuration (enabling the Cloud connection, mapping variables, and provisioning) is documented with the PLC IDE software itself, in [PLC IDE Cloud Support](https://docs.arduino.cc/software/plc-ide/tutorials/plc-ide-cloud-support/). That tutorial uses an Opta™ as its example device.
