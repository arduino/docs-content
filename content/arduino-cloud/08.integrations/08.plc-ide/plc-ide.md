The **Arduino® PLC IDE** — used to program Arduino industrial products such as the Portenta Machine Control and Opta® with IEC 61131-3 languages — can connect its projects to Arduino Cloud. This lets PLC variables be published to the Cloud, visualized on dashboards, and shared with the rest of the platform, bridging industrial control programs with Arduino Cloud's IoT tooling.

## How It Works

A device programmed with the PLC IDE runs two program layers that work together:

- **The PLC program**, written in an IEC 61131-3 language (Ladder Diagram, Sequential Function Chart, Function Block Diagram, Structured Text or Instruction List). It handles the industrial logic, such as reading inputs and sensors, for example over Modbus or the device's I/O pins.
- **The Arduino sketch**, which connects the device to Arduino Cloud and exchanges [Cloud Variables](/arduino-cloud/things-data/cloud-variables) with it.

The two layers exchange data through **shared variables** defined in the PLC IDE. In the sketch, you read values coming from the PLC program with `PLCOut.<variableName>` and send values to it with `PLCIn.<variableName>`. This lets data flow in both directions: the PLC program can publish readings to Arduino Cloud, and values set in Arduino Cloud, for example from a dashboard, can be sent to the PLC program.

## Hardware & Software Needed

- A PLC IDE compatible device with connectivity, such as an Opta® WiFi.
- The [Arduino PLC IDE](https://www.arduino.cc/en/software#arduino-plc-ide), version 1.0.6 or later.
- An [Arduino account](https://login.arduino.cc/login).

## Setting Up the Integration

The setup follows these main steps:

1. In Arduino Cloud, [add the device](/arduino-cloud/devices/devices-overview), create a [Thing](/arduino-cloud/things-data/things), and add the Cloud Variables you want to exchange with the PLC program.
2. In the PLC IDE, define the **shared variables** that the PLC program and the Arduino sketch use to exchange data.
3. In the PLC IDE's Arduino sketch, use the Cloud configuration generated by Arduino Cloud and map each Cloud Variable to a shared variable with `PLCIn` and `PLCOut`.
4. Write the PLC program that reads and writes the shared variables, then download the project to the device.
5. Create a [Dashboard](/arduino-cloud/dashboards/dashboards) to monitor and control the device.

For the complete walkthrough, including the example project for Opta, see [Using PLC IDE With Arduino Cloud](https://docs.arduino.cc/software/plc-ide/tutorials/plc-ide-cloud-support/).
