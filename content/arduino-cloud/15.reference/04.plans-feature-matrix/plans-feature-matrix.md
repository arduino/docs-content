A side-by-side comparison of what each Arduino Cloud plan includes. Use it to pick a tier or to understand why a feature is locked. For current pricing and the authoritative limits, see [Plans, Limits & Quotas](/arduino-cloud/spaces-plans-account/plans-limits-quotas).

<Alert type="info">

Plan limits, such as the number of Things, data retention and compile time, change over time. This page shows which features each plan includes. For the current numbers and prices, see the [Arduino Cloud plans page](https://cloud.arduino.cc/plans) and your [Plan Usage](https://app.arduino.cc/plan-usage).

</Alert>

## Feature Comparison

| Feature | Free | Maker | Team / Enterprise |
|---|---|---|---|
| Things | Limited | More | Scales with the plan |
| Historical data retention | Shortest | Extended | Longest |
| Over-the-air (OTA) updates | See [plans page](https://cloud.arduino.cc/plans) | Yes | Yes |
| Triggers / alerts | — | Yes, with a daily notification quota | Yes |
| Advanced widgets (Advanced Map/Chart, Image Map) | — | Yes | Yes |
| Dashboard sharing | — | Yes | Yes + RBAC |
| API access | Limited | Yes | Yes |
| Compilations | Limited per day | Unlimited | Unlimited |
| Node-RED integration | — | Yes | Yes |
| Fleet management / RBAC | — | — | Yes |
| Custom branding / white labeling | — | — | Yes |
| Data export (e.g. AWS S3) | — | — | Yes |

School plans add shared spaces with role permissions and classroom tools. See [Arduino Cloud for Education](/arduino-cloud/education).

<Alert type="note">

The three plan-gated dashboard widgets — [Advanced Map](/arduino-cloud/dashboards/track-location-map), [Advanced Chart](/arduino-cloud/dashboards/multiple-variable-chart), and [Image Map](/arduino-cloud/dashboards/image-map-widget) — appear in a locked "Upgrade to unlock" state on the Free tier. See the [Widget Catalog](/arduino-cloud/reference/widget-catalog).

</Alert>
