<FeatureDescription>

This product expands the Nano XL Link development board's capabilities by adding robust industrial connectivity via CAN bus, RS485, and Ethernet. Serving as both a DIN-rail-mountable solution and a reference design, the Nano XL Link Connector Carrier is the ultimate tool for a seamless transition from rapid prototyping to production-ready deployments.

</FeatureDescription>

<FeatureList>
<Feature title="Industrial Communication Interfaces" image="robot-arm">

Equipped with robust screw terminals for RS485 and CAN bus connections, ensuring reliable data acquisition and heavy machinery control even in high-vibration industrial environments.

</Feature>

<Feature title="Built-in Ethernet Port" image="connection">

Transform your setup into a wired IoT gateway. The integrated RJ45 Ethernet port facilitates secure, real-time data transmission to local SCADA systems or cloud analytics servers.

</Feature>

<Feature title="Wireless Expansion Support" image="wifi">

Features a dedicated 2x4 female header specifically designed to host an ESP8266 (ESP-01) WiFi module, allowing you to easily upgrade your wired infrastructure with wireless communication capabilities.

</Feature>

<Feature title="Plug-and-Play Ecosystem" image="communication">

Accelerate prototyping with the onboard Qwiic I2C connector, enabling frictionless integration with a wide range of external sensors and modules without soldering.

</Feature>

<Feature title="Full Pinout Access & Debugging" image="hw-pin">

Dual 2x20 breakout headers expose all standard and extended host board pins. Additionally, a dedicated 2x5 1.27mm SWD connector provides deep access for low-level programming and advanced debugging.

</Feature>

<Feature title="Industrial Power Input" image="power">

The dedicated Power IN screw terminal accepts a wide +7-24V input range (VIN) to power the carrier, protected by onboard polarity-reverse and TVS diodes for electrical safety.

</Feature>
</FeatureList>
