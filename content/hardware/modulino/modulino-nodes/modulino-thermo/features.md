<FeatureDescription>
The Modulino™ Thermo module measures temperature and humidity, suitable for climate control, environment monitoring, or weather station projects. It is compatible with any Arduino board with a Qwiic connector. Note that the Modulino Thermo is available in two hardware versions: boards marked V0.5 or later use the GXHT30C sensor, while earlier boards use the HS3003 sensor.
</FeatureDescription>

<FeatureList>
  <Feature title="Beginner Friendly" image="led">
    Guided examples show you how to read environmental data, making it ideal for classroom experiments or home projects involving temperature and humidity.
  </Feature>
  <Feature title="Qwiic & Solderable Pins" image="connection">
    The Modulino Thermo module connects via Qwiic cables to any Arduino board with a Qwiic connector. If needed, solderable pins let you wire it directly.
  </Feature>
  <Feature title="Two Hardware Versions" image="hw-pin">
    Boards marked V0.5 or later use the GXHT30C sensor (I²C address 0x45), while earlier boards use the HS3003 sensor (I²C address 0x44). Both versions share the same library API, so existing sketches work without changes.
  </Feature>
</FeatureList>
